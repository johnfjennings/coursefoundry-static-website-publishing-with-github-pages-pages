Build and Publish Your Portfolio Website with GitHub Pages

A step-by-step tutorial for students creating a professional portfolio website, linked to their Git repositories and hosted free on GitHub Pages.
Author

Mr. John Jennings

Overview

When you apply for a work placement or a graduate role, employers want evidence: what have you built, how did you build it, and can they see it? You probably already have that evidence scattered across many Git repositories - coursework, group projects, hackathon entries, personal experiments. This tutorial shows you how to gather the best of it into a single, professional portfolio website that you own, published free as a static website on GitHub Pages.

You will use Quarto to write your pages in Markdown, render them to plain HTML, and publish them from a GitHub repository. No servers, databases or hosting fees are involved.

What You’ll Build

By the end of the tutorial you will have a live website at https://<your-username>.github.io containing:

  • A home page that introduces you and what you’re looking for (placement, graduate role, internship)
  • A projects page with a card for each showcased project, linking to its GitHub repository and any live demo
  • Individual project write-ups explaining the problem, your role, the technologies and the outcome
  • An about / CV page with your skills, education, achievements and contact links
  • A repeatable workflow for updating the site whenever you finish new work

Who This Is For

Students preparing for a work placement or graduation who already use Git and GitHub for their coursework. You don’t need any web design experience - if you can write a README and run git push, you can complete this tutorial.

TipTime needed

Allow around 4-6 hours in total. Steps 1 and 4 (choosing and writing up your projects) take the longest - and matter the most.
